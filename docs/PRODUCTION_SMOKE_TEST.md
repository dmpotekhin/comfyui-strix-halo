## 4. Почему тест остановлен

Авторизоваться под аккаунтами нечем, и все доступные обходные пути запрещены условиями задачи
или моими правилами:

| Путь | Состояние |
|---|---|
| Пароли аккаунтов | неизвестны; в чате не принимаю, придумывать нельзя |
| Сохранённые логины в браузере | нет: `browser_vault list` → пусто |
| Живая сессия `sveta` | её cookie лежит в таблице `sessions`; извлекать токен из БД запрещено прямым указанием |
| Истёкшие сессии `dmitry2`, `polina` | недействительны, восстановить без входа нельзя |
| Браузер | открывает Studio, `document.cookie` пуст, `/api/auth/me` → 401 |
| Обход авторизации | запрещён: «не пытайся обходить авторизацию» |

По разделу 3 задания («если сессия истекла — остановись на соответствующем аккаунте, сообщи,
кому необходимо войти через браузер, не пытайся обходить авторизацию») тест остановлен на всех
трёх аккаунтах сразу: без входа невозможно ни выполнить шесть задач, ни проверить изоляцию
через API.

Владелец решил (19:15 MSK) зафиксировать блокировку в документе и ждать, пока вход не будет
обеспечен. Вариант с маскированным вводом паролей через хранилище Hermes и вариант с
самостоятельным запуском задач владельцем отклонены.
