## What this inventory means

- **Image generation and editing: covered** at SDXL quality, including inpaint, outpaint, img2img,
  upscale, IP-Adapter character consistency.
- **Video: covered** by exactly one model family (Wan 2.2 TI2V 5B). No video-to-video, no
  interpolation, no second opinion from LTX/SVD.
- **Speech: covered** — TTS in Russian and English (Piper) and transcription with subtitles (whisper.cpp)
  as host tools, because ComfyUI 0.15 has no local speech node.
- **Music: still not possible.** No ACE-Step weights (Stage R, 7.69 GiB, needs approval).
- **Structure control: partially covered.** Canny ControlNet works; depth/lineart need preprocessors and
  a depth model, both pending approval.
- **Instruction editing: not possible.** Qwen-Image-Edit and FLUX Kontext weights are absent.

## Integrity

Sizes are verified against the files on disk. SHA-256 is **not** recorded for any installed model
(the original downloads predate this studio), so integrity is currently "size + loads successfully",
marked `observed` rather than `verified`. The download manager records SHA-256 when the source
publishes one; future installs will be hash-verified.
