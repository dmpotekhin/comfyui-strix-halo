## 2. Запуск после включения ноутбука

Один скрипт, ничего помнить не надо:

```bash
cd ~/workspace/comfyui-strix-halo && ./start.sh
```

Что он делает: проверяет docker-демон (ждёт до 60 с) → проверяет `/dev/kfd` и `/dev/dri` →
`docker compose up -d` → ждёт HTTP 200 от ComfyUI (до 180 с) → печатает адрес, устройство, VRAM,
число чекпойнтов. Модели не перекачиваются: они лежат в `models/` (23.42 GiB) и переживают перезапуск.

Проверено на этой машине: холодный старт (контейнер остановлен) — **готово за 5 с**.
Остановить студию: `./stop.sh` (данные сохраняются).

**Состояние на 26.10 03:20: контейнер ОСТАНОВЛЕН** по просьбе пользователя (освобождение
ресурсов). Значит завтра `./start.sh` обязателен — сам контейнер не поднимется.

Автозапуска нет намеренно: `restart: "no"` в `compose.yaml`, студия поднимается только по твоей команде.
Если захочешь, чтобы ComfyUI стартовал сам при включении ноутбука — скажи, включу (одна строка
`restart: unless-stopped` в `compose.yaml` или systemd-юнит пользователя).

Ручная проверка «всё ли живо» (если что-то пошло не так):

```bash
cd ~/workspace/comfyui-strix-halo
docker ps --filter name=comfyui-strix-halo --format '{{.Names}} {{.Status}}'
curl -s http://127.0.0.1:8188/system_stats | head -c 200
docker compose logs --tail 50
```

## 4. План этапа 7 (сценарий) — что будет сделано после «продолжай»

1. Прочитать сочинение (текст или фото). Фото остаётся локально: распознавание — локальными средствами,
   без отправки в облачные сервисы. Если почерк нечитаем машинно — попрошу продиктовать текст.
2. Разобрать историю: герой, завязка, 3–5 ключевых событий, финал, мораль.
3. Собрать сценарий на **8–12 сцен**: для каждой — описание кадра, что происходит в движении
   (2 с), реплика/закадровый текст, длительность.
4. Показать сценарий и раскадровку на утверждение. **Дальше не идти без «ок»**.
5. Только после утверждения — этап 8: контрольные кадры всех сцен стилем animagine,
   проверка непрерывности персонажа между сценами.

Ограничения, о которых договорились: одна сцена = один клип 2 с; количество объектов в промпте
модель соблюдает плохо (проверено на «флотилии корабликов»), поэтому описания сцен делаем простые
и по одному главному действию.

## 5. Открытые вопросы, на которые понадобится ответ

1. **Сочинение**: текст или фото? Если фото — читаемый ли почерк (если нет, продиктуешь).
2. **Длительность мультфильма**: 1 мин (≈20 клипов, ~1.5–2 ч генерации)
   или 2 мин (≈40 клипов, ~3–6 ч). Можно решить после сценария.
3. **Голос рассказчика**: мужской/женский, спокойный «сказочный» — понадобится на этапе 9
   (русский TTS, локально).
4. **SVD (8.9 ГБ)**: нужен только если потребуется точная стыковка «рисунок → видео»
   без перерисовки сцены. Сейчас не нужен, решение отложено.

## 6. Чего делать нельзя (правила остаются в силе)

- Никаких облачных AI-сервисов и облачных узлов ComfyUI (Kling/Grok/Magnific/Recraft/Stability/
  Bria/ByteDance/Wavespeed/HitPaw — они есть в образе, но не используются).
- Фото сочинения, аудио и производные материалы не отправлять наружу.
- Не менять драйверы/ядро/BIOS/Docker-настройки (УРОВЕНЬ C), не удалять контейнеры/образы/модели
  (УРОВЕНЬ D) без отдельного подтверждения.
- Новые скачивания моделей — только после согласования размера и назначения.
